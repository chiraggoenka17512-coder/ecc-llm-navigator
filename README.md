# ⚡ Agent Compass — Neural Semantic Guide for Rules, Agents, Workflows & Skills

> **The Universal Semantic Architecture Prescriber** for [Affaan M's ECC (Everything Claude Code)](https://github.com/affaan-m/ECC), [Addy Osmani's Agent Skills](https://github.com/addyosmani/agent-skills), and [K-Dense Scientific Skills](https://github.com/K-Dense-AI/scientific-agent-skills).

Type any natural language development need or problem (e.g. *"Flaky tests in CI pipeline"*, *"HIPAA healthcare backend with security audit"*, *"Dynamic glassmorphism iOS UI"*), and our **in-browser 384-dimensional ONNX neural vector engine** instantly matches and prescribes your exact **4-Pillar Stack**:

1. 📋 **Most Required Rules**: Enforced coding style, testing standards, pattern constraints, and security policies.
2. 🤖 **Most Required Agents**: Specialist personas to review, plan, solve, and evaluate.
3. ⚡ **Most Required Workflows**: Step-by-step slash execution pipelines and phase gates.
4. 🎯 **Most Required Skills**: Deep domain playbooks and automated tools.
