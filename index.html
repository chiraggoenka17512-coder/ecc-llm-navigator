DEPLOYMENT GUIDE

Deploying to GitHub Pages

1️⃣ Create a New GitHub Repository

Go to github.com/new and create a public or private repository (e.g., ecc-llm-navigator).

2️⃣ Push This Repository

Run these commands in terminal:

git remote add origin https://github.com/<your-username>/ecc-llm-navigator.git
git branch -M main
git push -u origin main
3️⃣ Enable GitHub Pages

In your GitHub repo, navigate to Settings → Pages → Build and deployment.
Under Source, select GitHub Actions (a pre-configured deploy.yml workflow is already included in this project!).
